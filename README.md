# Hospital UI

A React application demonstrating UI for hospital bed availability system with user and hospital sides.

## Features

- User Side: Search hospitals, view lists and details, status indicators.
- Hospital Side: Login, dashboard, update beds, manage status, activity log.

## Installation

1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`

## Usage

Navigate through the app using the header links. All interactions are UI-only, no backend.
